A GitHub-compatible git forge in one Node process with no dependencies: git smart HTTP (protocol v2 and v0, shallow/thin-pack, fast-forward enforcement), REST v3 (repos, branches, commits, contents, labels, issues, pulls), GraphQL v4 (viewer, repository, connections with cursors, mutations, introspection) and MCP (era 2026-07-28, 8 tools). Deterministic seeded timestamps, in-memory store, response caches on the hot paths.

## Run it

```sh
node --experimental-strip-types main.ts
```
